# Hospital-Emergency-Department-Queue-Management-System

🏥 Hospital Emergency Department Queue Management System
📌 Overview
A Python-based simulation system designed to model and manage patient queues in a hospital emergency department. The system simulates patient arrivals, triage priorities, waiting times, and available medical resources.

✨ Features
Patient arrival simulation
Doctor and nurse resource management
Interactive GUI 

🛠️ Technologies
Python
SimPy
NumPy
Pandas
Matplotlib
Tkinter / CustomTkinter

📊 Outputs

The system provides:
Total patients
Patients served
Average waiting time
Maximum waiting time
Average queue length
Resource utilisation
Performance charts

🚀 How to Run
pip install -r requirements.txt
python main.py
